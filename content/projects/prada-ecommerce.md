## Overview

At Codeland S.r.l (Milan), I served as Lead Front-End Engineer on the Prada e-commerce project: a high-traffic, high-stakes retail platform where visual perfection is a brand requirement, not a preference.

## What I owned

**UI reliability.** I owned UI bug-fixing plus the AJAX and error-handling layers, the unglamorous code that decides whether a checkout survives a flaky connection.

**Mentorship.** I mentored three junior React developers on component architecture and state-management patterns, growing the team's capacity while shipping.

**Luxury-grade quality bar.** On a brand like this, a misaligned element is a defect. The work sharpened my habits around pixel-accurate implementation, cross-browser rigor and graceful degradation.

## Related enterprise work

The same period included re-engineering UniCredit's legacy Dimensione Sociale platform on AEM 6.5 and LDAP (~40% efficiency gain), migrating Java Spring Boot services to AWS (~20% latency reduction), and introducing Apache Kafka event-driven patterns for asynchronous processing, plus frontend work for MSC's Explora Journeys, Quattroruote and Cucchiaio d'Argento.
